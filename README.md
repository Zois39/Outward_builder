# Outward Character Builder

## 📁 Структура проекта

```
outward/
├── index.html          # Главная страница
├── style.css           # Стили
├── data_helmets.js     # 70+ шлемов
├── data_armors.js      # 70+ брони
├── data_boots.js       # 70+ ботинок
├── data_backpacks.js   # Рюкзаки и фонари
├── data_weapons.js     # 100+ оружия
├── data_skills.js      # Навыки с парами
├── data_other.js       # Прорывы, фракции, квесты
└── logic.js            # Вся логика
```

## 🔄 Версии

- **v2.0** (2026-10-23) — Русские названия, картинки, логика фракций, полный перечень бонусов

## 💾 Бэкапы

Все бэкапы хранятся в `/backups/`:
- `outward_builder_YYYYMMDD_HHMMSS/` — версия с датой
- `outward_builder_LATEST.zip` — последняя версия

## 🚀 Использование

1. Распакуй архив
2. Открой `index.html` в браузере
3. Всё работает офлайн!

## 🛠️ Разработка

Перед изменениями запускай:
```bash
python backup.py
```
